STM32CubeMX Software V6.18.0 / June-2026
Major release :
  • Added support for new microcontrollers in the STM32U3 series, and STM32H5 series.
  • Added support for new boards: NUCLEO-U345RC-Q, NUCLEO-U366RE-Q, NUCLEO-U366E-DK, and NUCLEO-H553ZG
  • Added Start From Board feature for NUCLEO-U345RC-Q, NUCLEO-U366RE-Q, and NUCLEO-H553ZG
  • Released the following new features:
    • Renamed all STM32CubeMX installers.
    • Added direct memory access (DMA) comparison to the Compare projects feature.
    • Removed the JxBrowser dependency.

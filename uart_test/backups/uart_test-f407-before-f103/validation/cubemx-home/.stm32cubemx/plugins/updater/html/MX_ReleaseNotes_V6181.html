STM32CubeMX Software V6.18.1 / July-2026
Minor release :
  • This patch release addresses issues that STM32CubeMX 6.18.0 introduced.
  • This release includes the following fixes:
    • Resolved a download error affecting crdb.zip during data updates.
    • Resolved errors that could occur when opening projects created with STM32CubeMX versions earlier than 6.18.0 when PCC is enabled.
    • Resolved the issue about clock configuration maximum value on STM32H743 and STM32H753 when using STM32CubeMX 6.18.0.
